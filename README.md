# CPSC 317 Tutorial Slides

## About

I made these slides over my last two terms as a CPSC 317 TA. I'm sharing them in case they're helpful to future TAs.

These are not official course materials. Use whatever is helpful, and feel free to change anything.

## How to Use

- The [shared Google Drive](https://drive.google.com/drive/folders/1gN4XpJVkrRdUYh8Xq5RmTiFIr8IjG44e?usp=sharing) is read-only. Make a copy of a deck before editing it.
- Each tutorial folder also has a `.pptx` backup. Some folders include a `teaching.md` with prep notes, teaching tips, and a suggested timeline.
- Some decks use hidden slides as speaker notes. Check them before teaching.
  - When sharing the slides with students, check with the teaching team about whether to include the hidden slides.
